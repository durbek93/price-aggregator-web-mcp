# Rules for AI Assistant

## Error Handling & Code Fixes (Handling Errors & Applying Changes)
- Whenever an error, failure, error log, or codebase/system issue is detected:
  1. Immediately inform the user about the error.
  2. Describe the nature of the error and its root cause in detail.
  3. Propose a specific solution / fix plan.
  4. **ALWAYS wait for explicit user confirmation** before making any changes or applying fixes to the code.
