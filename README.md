# Price Aggregator Web & Telegram Ecosystem

Независимая многопользовательская веб-панель и экосистема Telegram-агентов для фармацевтического анализа рынка Узбекистана. Система автоматизирует сбор прайс-листов дистрибьюторов, объединяет их в единый сводный прайс-лист с использованием нечеткого сопоставления названий и предоставляет аналитические отчеты об изменении цен с помощью искусственного интеллекта.

---

## 🌟 Ключевые возможности

1. **Автоматический сбор прайсов (Scout Agent)**: Модуль мониторит Telegram-каналы дистрибьюторов, автоматически скачивает новые Excel-файлы и загружает их на бэкенд.
2. **Гибкий парсинг Excel**: Автоматическое определение структуры таблиц (столбцов с наименованием, ценой, производителем и остатком) с поддержкой кастомных пресетов под сложных дистрибьюторов (Гранд Фарм, Хожи Акбар, Delpharm и др.).
3. **Каталогизация и Синонимы**: База канонических названий препаратов и их синонимов для точного нечеткого сопоставления (Union-Find + расстояние Левенштейна).
4. **Интеллектуальный бот-аналитик (Gemini 2.5 Flash)**:
   - **Еженедельный отчет**: Автоматический анализ лидеров рынка, динамики цен и дефицита после сборки сводного прайса.
   - **Анализ по производителю**: Генерация отчета о динамике цен конкретного производителя за последние 2-3 дня по запросу в чате (например, *«анализ цен КРКА за 3 дня»*).
   - **Анализ по препарату**: Детальный срез рынка с ценами и наличием конкретного препарата у всех дистрибьюторов по текстовому запросу (например, *«сделай анализ цен по препарату Виферон 150»*).
5. **История и soft-archiving**: Автоматическое перемещение старых версий прайс-листов в архив `history` при загрузке новых файлов с тем же именем, что позволяет отслеживать динамику цен во времени.

## 🛠 Технологический стек

- **Бэкенд**: Python 3.10+, **FastAPI** (REST API), **SQLAlchemy 2.0**, **PostgreSQL**.
- **Фоновые задачи**: **Redis** + **Celery** (многопоточная фоновая обработка Excel).
- **Фронтенд**: **React 18** (Vite), CSS-переменные (Glassmorphism & Neon Dark Mode).
- **Интеграция Telegram**: **Aiogram v3**, **Pyrogram** (клиент-парсер).
- **Интеллект**: **Gemini 2.5 Flash API** (асинхронное выполнение в Executor-пуле).

## 🚀 Быстрый запуск

### 1. Настройка переменных окружения
Создайте файл `.env` в корневом каталоге на основе шаблона `.env.example`:
```bash
cp .env.example .env
```
Заполните необходимые ключи:
- `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` (для работы Scout Agent).
- `ANALYST_BOT_TOKEN` (токен Telegram-бота аналитика).
- `GEMINI_API_KEY` (ключ Google AI Studio).
- `INTERNAL_API_KEY` (секретный ключ для коммуникации агентов с бэкендом).

### 2. Запуск контейнеров
Запустите сборку и старт всех сервисов через Docker Compose:
```bash
docker compose up --build -d
```

Система автоматически поднимет PostgreSQL, Redis, FastAPI-бэкенд, React-фронтенд (на порту `5173`), Celery-воркер, бота ручной загрузки прайсов, Scout Agent и AI Analyst Bot.

## 🧪 Тестирование и верификация

Для запуска автоматических интеграционных тестов правильности парсинга прайс-листов и проверки рефакторинга выполните команду внутри контейнера бэкенда:
```bash
docker exec price_aggregator_backend python /app/test_refactoring.py
```
Тест проверяет:
1. Корректность распознавания структуры таблиц Excel.
2. Нечеткую группировку и сопоставление по каталогу.
3. Поиск цен и расчет динамики по препарату *«Анаферон капли»*.
4. Выгрузку цен по производителю *«KRKA»*.
